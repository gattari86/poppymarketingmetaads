================================================================================
POPPY ADS MANAGER - CODEBASE ANALYTICS EXPLORATION SUMMARY
================================================================================

EXECUTIVE SUMMARY:
The Poppy Ads Manager currently displays only campaign management metrics
(campaign counts, statuses) with NO performance/analytics data. Meta Graph API
insights endpoints are available but not implemented.

================================================================================
SECTION 1: CURRENT METRICS DISPLAYED
================================================================================

Dashboard Level:
  - Active Campaigns count (ACTIVE status)
  - Paused Campaigns count (PAUSED status)
  - Total Campaigns count

Campaign Management Level:
  - Campaign Stats: Total, Active, Paused
  - Campaign Details: Name, Status, Objective, Budget, Created Date
  - Ad Set count per campaign
  - Ad count per ad set
  - Ad status (ACTIVE/PAUSED only)

Data Fetched BUT Not Displayed:
  - daily_budget (displayed in campaigns list)
  - lifetime_budget (available but unused)
  - targeting config (available but unused)
  - created_time, updated_time (available but unused)

NOT Fetched (Available in Meta API):
  - Impressions
  - Clicks
  - Spend
  - Reach
  - Frequency
  - Actions/Conversions
  - CTR (Click-Through Rate)
  - CPC (Cost Per Click)
  - CPM (Cost Per Mille)
  - ROAS (Return on Ad Spend)

================================================================================
SECTION 2: AVAILABLE META API ENDPOINTS FOR AD/CAMPAIGN PERFORMANCE
================================================================================

Currently Used Endpoints:
  1. GET /me/adaccounts
     - Purpose: List user's Meta ad accounts
     - Fields: id, name, currency, account_id, account_status

  2. GET /{act_adAccountId}/campaigns
     - Purpose: List campaigns in ad account
     - Fields: id, name, status, objective, created_time, updated_time,
               daily_budget, lifetime_budget

  3. GET /{campaignId}/adsets
     - Purpose: List ad sets in campaign
     - Fields: id, name, campaign_id, status, targeting, daily_budget,
               lifetime_budget, created_time, updated_time

  4. GET /{adSetId}/ads
     - Purpose: List ads in ad set
     - Fields: id, name, adset_id, campaign_id, status, creative,
               created_time, updated_time

  5. GET /{adAccountId}/adrules_library
     - Purpose: List automated rules
     - Fields: id, name, status, evaluation_spec, execution_spec,
               created_time, updated_time

AVAILABLE BUT NOT IMPLEMENTED - INSIGHTS ENDPOINTS:
  6. GET /{campaign_id}/insights
     - Purpose: Campaign performance metrics
     - Available Fields: spend, impressions, clicks, reach, frequency, actions,
                        action_values, ctr, cpc, cpm, date_start, date_stop

  7. GET /{adset_id}/insights
     - Purpose: Ad set performance metrics
     - Same fields as campaign insights

  8. GET /{ad_id}/insights
     - Purpose: Individual ad performance metrics
     - Same fields as campaign insights

  9. GET /{ad_account_id}/insights
     - Purpose: Account-level aggregated metrics
     - Same fields as campaign insights

All Insights Endpoints Support:
  - Query Parameters: date_start, date_stop (date range filtering)
  - Optional: breakdown_by=time,device,platform
  - Optional: aggregation_unit=day,week,month
