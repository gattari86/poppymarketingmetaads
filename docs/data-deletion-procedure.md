# Data Deletion Procedure

This document outlines the data deletion procedures for Poppy Marketing Ads Manager, matching the information displayed on the `/data-deletion` page.

## Overview

Users have the right to request deletion of their personal data from Poppy Marketing Ads Manager. This procedure ensures we comply with GDPR, CCPA, and other privacy regulations.

## User-Initiated Data Deletion

### Method 1: Web Form (Recommended)

**Steps for User:**
1. Visit `app.poppymarketingandconsulting.com/data-deletion`
2. Enter their email address
3. Click "Request Data Deletion"
4. Confirm submission

**What Happens:**
- Request is logged with timestamp
- User receives confirmation email
- Data deletion team is notified
- Process begins within 1 business day

### Method 2: Direct Email

**Steps for User:**
- Email: support@poppymarketingandconsulting.com
- Subject: "Data Deletion Request"
- Body: Include email address and any relevant account details

**What Happens:**
- Email is logged
- Request is processed same as web form
- User receives acknowledgment email

## Processing Timeline

| Phase | Duration | Action |
|-------|----------|--------|
| Initial Receipt | Immediate | Log request, send confirmation |
| Verification | 1 business day | Verify user identity |
| Data Collection | 2-3 business days | Collect all associated data |
| Deletion | 2-3 business days | Securely delete all data |
| Confirmation | 1 business day | Send completion email |
| **Total** | **30 days** | Complete process |

## Data Deletion Checklist

**User Account Data:**
- [ ] User profile (name, email, login history)
- [ ] Session records
- [ ] Authentication logs
- [ ] Device information

**Usage Data:**
- [ ] Campaign creation records
- [ ] Ad set management history
- [ ] Ad creation and edits
- [ ] Rule creation records

**Preferences & Settings:**
- [ ] Selected ad account preferences
- [ ] Dashboard settings
- [ ] Notification preferences

**Metadata:**
- [ ] Created/modified timestamps
- [ ] Login IP addresses
- [ ] Referral source

## Legal Holds

**Data Retained by Law:**
- Tax records (7 years)
- Invoices (7 years)
- Court-ordered data
- Regulatory compliance data
- Fraud/abuse investigation logs

User will be notified of any data retained with specific retention periods.

## Compliance Standards

✓ GDPR Article 17 (Right to Erasure)
✓ CCPA Section 1798.105 (Right to Delete)
✓ LGPD Article 18 (Right to Deletion)
