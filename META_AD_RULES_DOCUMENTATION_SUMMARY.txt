EVALUATION TYPES
================================================================================

SCHEDULE:
  - Time-based evaluation
  - Runs on set intervals: DAILY, HOURLY, SEMI_HOURLY, CUSTOM
  - Predictable execution

TRIGGER:
  - Event-based evaluation
  - Fires when conditions change
  - Five trigger types:
    * STATS_CHANGE              Metric value changes
    * STATS_MILESTONE           Threshold reached
    * METADATA_CREATION         New entity created
    * METADATA_UPDATE           Entity modified
    * DELIVERY_INSIGHTS_CHANGE  Delivery metric changes

CONFIGURATION:

================================================================================
IMPLEMENTATION WORKFLOW
================================================================================

STEP 1: TEST WITH NOTIFICATION
  - Create rule with execution_type: "NOTIFICATION"
  - Verify filter logic triggers correctly
  - Review what entities would be affected

STEP 2: USE PREVIEW MODE
  - Call rule.create_preview() via API
  - Check number of affected entities
  - Validate it matches expectations

STEP 3: PILOT ON SUBSET
  - Add campaign ID filter
  - Enable on 1-2 test campaigns
  - Monitor for 3-7 days

STEP 4: MONITOR PERFORMANCE
  - Check rule history daily
  - Review execution results
  - Adjust thresholds if needed

STEP 5: SCALE TO PRODUCTION
  - Remove campaign ID filter
  - Enable across all campaigns
  - Continue regular monitoring

================================================================================
COMMON ERRORS & SOLUTIONS
================================================================================

RULE NOT TRIGGERING:
  → Check status is ENABLED
  → Verify thresholds are being met
  → Ensure sufficient data (impressions/spend)
  → Review time_preset window

RULE TRIGGERING TOO OFTEN:
  → Increase thresholds
  → Add more filter conditions
  → Change TRIGGER to SCHEDULE
  → Add minimum impression requirement

EXECUTION FAILS:
  → Verify account has sufficient budget
  → Check campaign/ad set is ACTIVE
  → Validate execution_type for entity_type
  → Review execution_options fields
